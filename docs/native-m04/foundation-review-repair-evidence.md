## Integration contracts

- `CoreEvents::subscribe(owner, channels, callback, cx)` and typed `CoreEvent` variants are preserved. Subscribe before starting output, keep the owner active while hidden, stop its producer before dropping it. There is no public hidden reserve-without-consumer API. At most 32 output channels may be owned. Unknown/unowned output is discarded, status is coalesced, active agent/PTY data is lossless until deliberate owner disposal. The product Tokio pool has 2 workers and at most 16 blocking/replacement workers. Backpressure owns the current producer payload rather than allocating a task per emit.
- M5 sends `SnapBegin` only; Owner owns macOS native movement/Windows manual movement and physical release detection. M5 capture-time move/up calls `update_pointer_gesture` and `end_pointer_gesture`; any up or missing pressed-left ends resize. This lane inspected sibling changes rather than editing surfaces.
- `CoreClient::start/shutdown` keep independent start/stop handles. Sibling-owned requests have 16 admitted independent work tasks and completion outcome logs. Canonical request variants/wires were not changed by this lane.
- `Preview::allow_desktop_integration` defaults false. Registry registration and primary tray/hotkey creation require opt-in; isolated core services remain disabled even when opted in.
- `Launcher::drain_state()` is awaited and `state_write_error()` is checked before retiring the instance or disposing event ownership. Cancelled save retains UI event subscriptions and writer maps, and reattaches the startup waiter.
