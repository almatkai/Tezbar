## Test corrections and preserved failures

The earlier model test assumed **client filtering** invalidates an in-flight Invoke, precisely the D5 defect. It now tests supersession by an actual newer **server search** and still rejects foreign callbacks and the old reply. A separate regression proves client filtering keeps the action token. No test was removed or skipped.

The original real Grid fixture sent Right while the search field was focused. Its tile-navigation assertion now gives focus to the grid; a separate test exercises the real focused-search caret path. The assertion remains `colour-4` after Right then Down.

Early compile errors, the cross-realm date failure, old fixture assumptions and the initial scrolling assertion are preserved as raw logs. `UniformListScrollHandle::logical_scroll_top_index()` falls back to ordinary child bounds; those are empty for the virtual list after paint. The final scrolling test checks its actual negative viewport offset and selected-row bounds instead. Uniform section headings also now have the same height as action rows.

No physical desktop, live Store/provider, Keychain, clipboard, signing, installed beta, production profile, Windows, GPU or RAM work was performed. The optional MenuBarExtra lifetime decision was presented separately; this candidate retains its core status owner when leaving a foreground screen and retires it on rerun/disable/uninstall/worker pruning/shutdown. Background control requests without a mounted view do not bypass the native source fence. They remain an explicit manual acceptance item.

Root focused results and hashes are in `focused-verification.json`. Full frozen native/bench/UI/build/MSRV/worker gates and fresh Claude Opus review remain follow-up gates, not inferred from older M11 or M9 pass counts.
