# Integrated M11 ownership

This receipt supersedes source-only draft claims only where an executed gate records evidence. The original HANDOFF, source-audit, map and upstream references remain historical and unchanged.

`main` retains private supervisor and Native V2 dispatch first. Explicit Preview parsing retains its marked OS-temp profile and resource/source guard. With no preview arguments, the native executable requests an opaque `production_launch::Admission`; no environment or IPC option constructs one. Dirty/bench builds are refused. macOS admission verifies the original pinned signature, helpers, exact designated requirement, bundle metadata and stream-hashed resource provenance before consulting HOME or resolving production paths. Windows admission refuses pending platform acceptance. This is connected to the same `run_app`, single instance, RuntimeOwner, GpuiHost, primary tray, core platform hotkey registry and eight-second quit path. The existing TEZBAR_DATA_DIR/TEZBAR_CONFIG_DIR overrides are consulted only after admission. The ordinary pnpm product remains Tauri.

Launcher owns the one `UiState`, canonical decoder/importer, writer mutex and persistence revision. Its `new_with_migration` completes bootstrap before hydration or attaches recovery state with the durable path disabled. Valid native defaults win even with importedLegacy=false. Corrupt native data is preserved. Missing/ambiguous/unsupported transport never means empty. An existing destination also wins the atomic no-replace commit, even after import was prepared. The recovery surface admits retry, quit, or an explicit two-step choice to initialize defaults without overwriting native or legacy files. Marker and imported fields are one atomic JSON, with no second marker/model. A private SQLite/WAL copy can recover quiescent bytes; the original is opened only through ordinary file reads and checked byte-for-byte by SHA256 before/after. Production OS-profile provenance is still O-LS.

`update_integration::Actor` runs on RuntimeOwner. Client commands and finite effects each have capacity 16; watch coalesces status and preserves the latest frame. App retains one receiver task and an abort-on-drop actor lease. Launcher owns status rows/task indicator and UI writes; existing Settings gets refreshes, and newly opened Settings reads retained Launcher status. CheckedAt produces one owner mutation per successful check, with the old status-event timestamp write removed. AutoUpdate is persisted through the existing M7 barrier. Channel changes carry an exact barrier ticket to ChannelFinished/Rejected. Quiesce pauses the same actor, cancels its one pending operation, and fences earlier completion effects before Launcher save/drain starts. A failed quit returns the artifact and resumes that actor. Late Launcher writes also prevent quit from claiming durability. The retiring single-instance lease is released after core shutdown and before relaunch. No channel/parser/signature/client authority was copied into App.

The portable updater owns one lazily initialized reusable HTTP client, including manual discovery; check requests retain 15 seconds and downloads 900 seconds. Existing endpoint/channel selection, public release fallback, minisign verification, extraction and signature pin remain authoritative. Successful download now publishes Ready; cancel/failure clears portable pending state. Actor owns one retained artifact and generation. Declined quit returns the artifact by an awaited bounded send; stale generations are discarded. Channel changes cannot consume a ready/installing artifact. Install failure permits a fresh check. macOS uses portable staging, pin verification, swap and rollback; backup retention is deliberate because successful process creation is not readiness proof. Windows preserves /P /R /UPDATE /ARGS plus each escaped argument separately. Real installer/signed-updater/relaunch acceptance remains open.

The packaging path is `pnpm native:check`, `pnpm native:build`, or explicit `scripts/build-release.mjs --app native --local-preview --resources <symlink-free staging root> --output <fresh OS-temp child>`. The latter builds the current native debug target and packages only explicit pinned resources with the preview identity/ad-hoc policy. It never chooses a public version or reads updater/private signing keys. The original release route is unchanged; native distributed assembly is refused while acceptance gates remain open. Headless packaging tests use dummy bytes, never installed app resources or production certificates.

`final-cutover-review.patch` and `final-cutover-inventory.json` are concrete, un-applied review artifacts. They pin relocations, preserve old TS oracle sources and prototype evidence, move signing/catalog/icon bytes without changing their values, list binary copies, update exact consumers and show the default build change. They do not prove dynamic import, Windows, signing, manual or RAM acceptance and are not approval to apply the patch. No original product file was removed.
