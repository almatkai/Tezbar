# Tezbar 0.3.0-beta.10

## macOS startup

- Fix the native app exiting immediately with `Designated requirement differs from the committed pin`. The startup verifier now reads the designated requirement from either output stream returned by `codesign`.
- Preserve the pinned certificate, Team ID, exact requirement and native-helper signature checks. Missing, different or ambiguous requirements remain rejected.
- Before packaging a macOS release, run the signed app's own installation check without opening windows or accessing a user profile. An app that fails startup admission cannot produce a DMG, updater archive or release receipt.

This update retains the native GPUI interface and the other changes from beta.9.
