# Tezbar 0.3.0-beta.10

## macOS startup

- Fix the native app exiting immediately with `Designated requirement differs from the committed pin`. The startup verifier now reads the designated requirement from either output stream returned by `codesign`.
- Preserve the pinned certificate, Team ID, exact requirement and native-helper signature checks. Missing, different or ambiguous requirements remain rejected.
- Before packaging a macOS release, run the signed app's own installation check without opening windows or accessing a user profile. An app that fails startup admission cannot produce a DMG, updater archive or release receipt.
- Register the configured launcher shortcut during production startup, before migration or optional core services can delay it. Production no longer inherits the isolated preview policy that disables shortcuts.
- Left-clicking the production menu-bar icon opens or focuses the launcher, including while startup is pending. Repeated clicks keep it open; the right-click menu retains Show, Settings and Quit.

## Background indexing

- Filter ignored build, Git and cache paths before they can fill the file-watcher queue and cause unnecessary index reconciliation. Real event-loss signals still trigger reconciliation.
- During reconciliation, skip unchanged file documents and reuse the SQLite UPSERT statement for changed files. Preserve rename, deletion and search-index recovery.
- Avoid writing terminal configuration when no saved session has expired.

## Background scheduling

- Wait for clipboard commands without a timer when native watching is off. Disabled capture still notices configuration changes within one second; enabled capture keeps its 100 ms cadence.
- Wake the file watcher for real events, event loss or shutdown instead of checking every 500 ms. Keep event batching and reconciliation behavior.
- Replace chat's permanent 250 ms ticker with one task for the earliest pending start deadline. Hidden runs still time out after 30 seconds; settled chat owns no timer.
- Retain Knowledge's external-database observation and download/backfill responsiveness.

This update retains the native GPUI interface and the other changes from beta.9. These changes reduce unnecessary indexing work; battery-life improvement still requires measurement on the installed build.
