## Google Calendar sign-in

- Fix Google Calendar authorization in Tezbar on Windows with the correct Raycast redirect and PKCE token exchange.
- Open a helper page when the browser cannot return automatically; complete sign-in by pasting the full redirect URL.
- Restore the previous Windows protocol handler after sign-in, cancellation, or timeout.
- Add optional Google Desktop Client ID and Client Secret preferences, with separate tokens for each client.
- Reject callbacks from a different sign-in attempt and keep ordinary Desktop clients on loopback redirects.

This testing Beta includes Windows x64 and macOS Apple Silicon installers with signed Tauri updater artifacts. Platform code-signing and notarization are not included. Existing Beta features, model files, and indexed content are preserved.
