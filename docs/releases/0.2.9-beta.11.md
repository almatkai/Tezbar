## Rust Core and Native V2

- Core application services now run in Rust. JavaScript compatibility extensions use an isolated worker that starts when needed. The interface remains React and TypeScript inside Tauri.
- Added eleven bundled Native V2 Rust replacements: Amphetamine, Audio Device, CleanShot X, Color Picker, GIF Search, Google Calendar, Google Search, Perplexity, Port Manager, Speedtest and Timers.
- The extension catalog shows canonical Tezbar replacements, actual Rust command coverage and unsupported commands. Native commands take priority over duplicate legacy commands.
- Native V2 is manifest schema 2; the remaining V1 catalog stays available through JavaScript compatibility.

## Reliability fixes

- Fixed the Windows test entry-point failure caused by the Common-Controls manifest dependency (`0xC0000139`).
- Timer forms preserve typed values across background refreshes. Timer sounds ship with the application and work without a legacy extension installation.
- Improved cancellation, native session lifecycle, color extraction and process identity validation in Port Manager.

## Coverage and beta limits

- Compiled native handlers cover 83/84 commands on macOS and 74/84 on Windows. These counts describe handler availability, not complete feature parity.
- Google Calendar requires your own Google Desktop OAuth client. CleanShot X features depend on the platform and installed capabilities. See [Native V2 QA](https://github.com/almatkai/Tezbar/blob/feat/rust-core/docs/NATIVE_V2_QA.md) for detailed limits and verification.
- Windows automated tests, CLI installation and the NSIS build passed. An interactive Windows GUI pass has not been performed.

This Beta includes Windows x64 and macOS Apple Silicon installers with signed updater artifacts. OS code-signing and Apple notarization are not provided in this testing preview.
