## Tezbar opens when you launch it

- The Tezbar launcher now opens automatically when you start the app.
- After an update restarts Tezbar, the launcher opens again so you can continue immediately and read **Release Notes**.
- The window uses your usual monitor placement and focuses the launcher input.
- macOS now uses the same thin update-check indicator as Windows.
- Releases without a build for your operating system are treated as having no available update.
