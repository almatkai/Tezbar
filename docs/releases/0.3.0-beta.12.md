# Tezbar 0.3.0-beta.12

The native extension catalog contains 111 records. Twenty-six have published artifacts. The new testing previews include Arc 0.1.0, Google Chrome and Brew on macOS, Linear, Slack, Notion 0.1.0 and Visual Studio Code 0.1.1 on macOS and Windows, and Lorem Ipsum 0.1.1 with HTML and Markdown commands. Existing local-import restrictions still apply.

The Rust host adds quicklink creation, clipboard content and capture services, audio playback and navigation. The GPUI extension views improve form focus, selected-row actions, optional launcher arguments and tray routing. The beta.11 chat, startup activation, idle processing and installation-admission changes carry forward.

Desktop acceptance and live account testing remain pending for the new previews.
