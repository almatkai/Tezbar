# Tezbar 0.3.0-beta.12

The native extension catalog contains 116 records. Thirty-one have publicly downloadable artifacts. The testing previews include GitHub, Obsidian, Coffee and Google Translate 0.1.1 on macOS and Windows, plus Apple Notes and Apple Reminders on macOS. They join Arc 0.1.0, Google Chrome and Brew on macOS, Linear, Slack, Notion 0.1.0 and Visual Studio Code 0.1.1 on macOS and Windows, and Lorem Ipsum 0.1.1 with HTML and Markdown commands. Unavailable public download references for Port Manager have been removed; its local-import-only policy and the other local-import restrictions still apply.

The Rust host adds quicklink creation, clipboard content and capture services, audio playback and navigation. The GPUI extension views improve form focus, selected-row actions, optional launcher arguments and tray routing. Native command migration preserves cleared and rebound shortcuts, keeps supported JavaScript fallbacks active, and defers uncertain history without blocking unrelated commands. The beta.11 chat, startup activation, idle processing and installation-admission changes carry forward.

Vault: opening a locked Vault asks for Touch ID or the Mac password right away. Cmd+C on a Vault search result unlocks the Vault if needed and copies the secret. Opening a Vault result from search selects that item in the list.

Desktop acceptance and live account testing remain pending for the new previews.
