# Tezbar 0.3.0-beta.13

Vault: Cmd+C on a Vault search result now shows its progress and outcome on that row instead of in the footer. The row badge changes to "Copying…" and, when the Vault is locked, "Unlocking…" while Touch ID or the Mac password is requested. A green "Copied · clears in 30 s" confirmation follows; a cancelled unlock or failed copy shows a red message on the same row. The badge returns after a few seconds, and closing the launcher or changing the search clears it.

The beta.12 extension catalog, Rust host services, native command migration and Vault changes carry forward unchanged.
