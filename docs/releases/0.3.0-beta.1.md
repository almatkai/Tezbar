# Tezbar 0.3.0-beta.1

Release date: 2026-11-01

This beta adds Vault, a local store for API keys, tokens, server logins and other secrets, and gives every nested screen the same header and footer as the launcher.

## Vault

- Store API keys, tokens, SSH keys, server logins, passwords and notes. Paste a value and Tezbar suggests a name and type; the note is optional.
- Unlock with Touch ID or the Mac login password. The vault key is a random 256-bit key kept in the macOS Keychain and read only after that check succeeds. Items are encrypted with AES-256-GCM in a single local file and never leave the device.
- Vault locks itself after 30 minutes without use. Unlocked secrets are wiped from memory when it locks.
- Vault item names appear in global search, so typing "main server" opens that item. Values and notes are never indexed.
- Press ⌘C on a vault result in the launcher to copy its value. A hint next to the query shows the shortcut, and the launcher confirms the copy. Copied secrets are marked as concealed, are skipped by Clipboard History, and are cleared from the clipboard after 30 seconds unless something else was copied.
- Press ⌘S on a text entry in Clipboard History to move it into Vault. The entry is removed from Clipboard History once saved.
- Shortcuts inside Vault: ⌘N new item, ⌘↵ save, ⌘E edit, ⌘⌫ twice to delete, ⌘L lock.
- Vault is available on macOS only. Windows shows that it is not supported yet.

## Search

- Names typed by ear in the other script now match: «клауд» finds "CloudFlare API Key", and Latin queries find Cyrillic titles. Files are excluded from this pass.

## Interface

- Nested screens (Clipboard, Extensions, Emoji, Notes, Snippets, Indexing, Permissions, System Monitor, Release Notes and extension commands) now use the launcher's header, back button, input and footer, so spacing and shortcuts read the same everywhere.
- Extension catalog images load from a WebP cache and show a placeholder until it is ready, instead of the full-size PNG or JPEG.
- The Extensions grid keeps its search field visible when the grid is empty.
- Extension icons, including remote ones, render in both catalog rows and the details pane.
- The emoji picker scrolls natively and no longer has an oversized top margin.
- Remove the settings icon from the Background tasks popover; it did nothing.

## Beta distribution

This beta continues the 0.2.9-beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
