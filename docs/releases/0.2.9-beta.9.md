## New launcher and app design

- Redesigned the launcher as one compact, flat sheet: a slimmer search row, one-line results with colored squircle icons, and a solid accent highlight for the selected result.
- Mode shortcuts (Deep Search, Terminal, AI) sit in the search row and step aside one by one as you type.
- The shortcut bar now floats over lists as frosted glass, so results scroll underneath it.
- Every view — clipboard history, snippets, notes, emoji, ports, extension store and more — now uses the same flat design with sentence-case labels and grouped key hints.
- Drag the window from anywhere in the search area.
- Leaving a view now returns to plain search instead of AI or terminal mode.

## Fixes

- Fixed garbled Unicode text in macOS clipboard history.
- Code blocks and syntax highlighting now follow the light theme.

This Beta provides signed Windows x64 and macOS Apple Silicon updates and installers.
