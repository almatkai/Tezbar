# Tezbar 0.3.0-beta.11

## AI chat

- Use the redesigned native conversation view, with message actions aligned under user messages and no bulk delete button in history.
- Return to the conversation list while a reply continues in the background. The list shows when an agent is starting, thinking, using tools, generating, or waiting for approval.
- Keep tool calls, thinking, and response text in arrival order. Fix a crash when scrolling a populated transcript.

## Startup and idle work

- Register the production shortcut during startup and open the launcher with a left-click on the macOS menu-bar icon.
- Validate the signed macOS app's startup requirements before packaging.
- Filter ignored paths earlier, skip unchanged indexing work, and avoid idle polling in the file watcher, clipboard, and chat.
