# Tezbar 0.2.9-beta.16

This beta reduces repeated background work in the Rust core while preserving search results, indexing recovery and extension integrity checks.

- Reuse Knowledge progress for unchanged data instead of repeatedly scanning the full semantic index. Count only the selected, available model and mark unavailable statistics as stale.
- Avoid repeatedly searching an already completed embedding queue. Select pending indexing work through the active job's database index.
- Skip extraction pacing for unchanged files and combine progress updates while keeping every completed file durable. Ignore watcher events inside excluded folders while preserving folder deletion and overflow recovery.
- Stop idle local models independently of long indexing passes, without interrupting active startup or inference.
- Index launcher deletions by category and path, and avoid rewriting unchanged apps and commands merely because a refresh has a new timestamp.
- Read macOS application metadata without launching plutil for each app, and reuse fuzzy-search buffers without reducing candidate coverage.
- Cache extension command lists with mutation and external-change checks. Package bytes are still verified before execution.

Regression tests cover scoped counts, cancellation, pause/resume, external changes, queue recovery, watcher deletions and process cleanup. No specific application CPU or memory reduction is claimed without a comparable release-build measurement.

## Beta distribution

This beta continues the beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
