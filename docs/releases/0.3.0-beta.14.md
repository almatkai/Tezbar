# Tezbar 0.3.0-beta.14

Notes: a selected note now shows rendered Markdown — headings, bold and italic text, inline code, tables, lists and links — instead of its raw symbols. Press Enter, double-click, or Cmd+E to edit; Esc or Cmd+E returns to the rendered note, and a second Esc goes back. New notes open in the editor.

Clipboard History: Cmd+N saves the selected text entry as a new note, keeping its Markdown. Concealed items, images and files are not saved.

Extensions: Tezbar checks installed extensions for updates shortly after launch and then every 12 hours. An extension with an update shows "Update available" in the Store list, an update banner with an Update button on its page, and "Update extension" in its footer; the status bar counts available updates, and Refresh checks immediately.

Color Picker: the colour wheel is now smooth and borderless, keeps tracking while dragging outside the wheel, sits in a compact panel, and no longer reports "Colour action is unavailable".

The beta.13 Vault, extension catalog and Rust host changes carry forward unchanged.
