# Tezbar 0.2.9-beta.15

Semantic Search settings stay responsive while large indexes are being processed, alongside extension and launcher fixes for macOS Apple Silicon and Windows x64.

- Read Semantic Search and chunking settings from initialized status instead of waiting behind full database counts. Large indexes no longer make these controls unavailable through that timeout path.
- Keep saved model and chunking-speed choices while background indexing updates its progress.
- Run supported Rust extensions as separate processes, including the LaTeX extension, with process cleanup and startup safeguards.
- Keep long command input within the launcher header and avoid stale extension icons when switching catalog entries.

## Beta distribution

This beta continues the existing native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
