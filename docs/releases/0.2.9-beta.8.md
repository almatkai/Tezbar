## Disabled system text selection and ghost dragging

- Disable text selection across all system launcher elements, rolling hints, search mode badges, argument chips, and results lists.
- Prevent accidental drag-and-drop of text snippets, icons, and links when moving the launcher window.
- Preserve text selection in search and input fields, text previews, and AI chat answers.

This Beta provides signed Windows x64 and macOS Apple Silicon updates and installers.
