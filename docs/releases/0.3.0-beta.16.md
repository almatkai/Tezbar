# Tezbar 0.3.0-beta.16

Color Picker: dragging on the Color Wheel is smooth again. Every drag step reaches the extension, the marker follows the pointer, and the "Colour action is unavailable" banner no longer flashes and shifts the page.

Window: the launcher window can be resized from extension pages, the Store, Terminal and AI Chat, the same as from the launcher.

The beta.15 Color Picker 1.0.1 update, extension Back fallback and Notes changes carry forward unchanged.
