# Tezbar 0.3.0-beta.6

Release date: 2026-11-04

This release brings background AI agent persistence, configurable execution permission modes with safety guardrails, idle memory trimming and WebKit hibernation, and layout fixes for the Color Picker extension.

## AI Agent: Background Execution & Approval Modes

- **Persistent background work:** The AI agent continues running, executing tools, and streaming thoughts even when you close the chat window, press `Escape`, or switch to other applications.
- **Dedicated stop shortcut:** Pressing `Escape` now returns you to the launcher without interrupting background agent tasks. Stopping an active agent run is bound explicitly to `⌘.` (Command+Period) and the UI stop button.
- **Approval mode picker:** Choose how bash commands are executed via the header dropdown:
  - **Request Review:** Every single command requires manual approval.
  - **Default:** Prompts before sensitive or mutating system operations.
  - **Auto (Preview):** Automatically approves safe developer and inspection commands (`git`, `cargo`, `npm`, `tsc`, `cat`, etc.) while asking before external modifications.
  - **Turbo:** Runs all commands autonomously with zero friction, while strictly intercepting destructive system commands.
- **Destructive command guardrails:** Irreversible actions (such as mass recursive deletions `rm -rf /`, `rm -rf ~`, raw drive formatting `mkfs`/`diskutil`, database drops `DROP DATABASE`, and fork bombs) are always intercepted and require explicit confirmation across all modes.

## Performance: Idle Memory Trimming & WebKit Hibernation

- **5-second debounced idle trim:** When the Tezbar window is hidden, a 5-second timer triggers a native memory reclaim cycle. If the window is reopened within the window, trimming is immediately cancelled.
- **SQLite memory release:** Invokes `PRAGMA shrink_memory;` on the dedicated SQLite thread, releasing page cache and search indexes back to the operating system.
- **OS memory pressure relief:** Triggers `malloc_zone_pressure_relief` on macOS and `SetProcessWorkingSetSize` on Windows to return unused heap pages to kernel memory.
- **WebKit cache purge & GC:** Signals the Webview renderer to clear unused object URLs, purge stale extension images, and run JavaScript garbage collection.

## Color Picker & Color Wheel

- **Responsive form width:** Forms containing the native Color Wheel now scale responsively up to 960px (`max-w-[960px]`) rather than being clamped to a narrow 640px column with unused space to the right.
- **Centered wheel presentation:** Fixed a WebKit flexbox aspect-ratio layout bug where the circular wheel was forced to the bottom half of the card, leaving an empty area above it. The wheel is now cleanly bounded (`380×380px`) and centered.
- **Format list scrolling:** Constrained the Color Wheel grid height (`max-h-[540px]`) so the 12 color format rows scroll neatly in the sidebar without stretching the wheel container vertically.

## Included from beta.5

- **Vault item icons:** Choose custom icons for any item from 43 built-in line icons in the editor (⌘E).
- **Extension form shortcuts:** Submit forms with ⌘↵ (Ctrl+↵ on Windows), Enter inserts a newline in text areas, and progress states cleanly clear in the footer.
- **Single-prompt forms:** Dedicated full-height prompt layout for single-textarea forms.

## Beta distribution

The macOS app keeps the pinned Apple Development certificate identity introduced in beta.4 (Team ID `UBRTH86SZ3`); it is not Developer ID notarized. The Windows installer continues the beta exception without Authenticode signing. Both updater artifacts carry Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64.
