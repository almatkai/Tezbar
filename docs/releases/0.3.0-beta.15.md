# Tezbar 0.3.0-beta.15

Color Picker 1.0.1: the Color Wheel no longer traps you. Esc and Back close the Color Wheel command, and a wheel opened from a result goes back to that result. The Store and your installed extensions list offer the update to Color Picker 1.0.0: it appears shortly after launch, or right away when you press Refresh in the Store.

Extensions: Esc and Back now leave any extension whose own Back answers with the same screen, with no screen, or with an error, instead of keeping you there.

Notes: when the launcher is shown again, a note returns in the mode you left it. A rendered note keeps the search field active; a note you were editing keeps the editor active.

The beta.14 Notes Markdown, Clipboard History "Save to Notes", extension update checks and Color Picker wheel changes carry forward unchanged.
