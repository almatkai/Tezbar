# Tezbar 0.2.9-beta.14

Deep Search reliability and a smaller optional semantic model for macOS Apple Silicon and Windows x64.

- Keep the current Deep Search query, results and selection when hiding and reopening the window while Tezbar stays running.
- Prioritize exact OCR phrases and apply the result limit after grouping matches by file, so one document cannot crowd out the results.
- Add Compact (Q4_K_M) alongside Standard (Q8_0) in Semantic Search settings. Existing Q8 selections are preserved; switching models retains extracted text and OCR and keeps each model's vectors separate.
- Verify model files, show actionable download and startup failures, and improve cancellation and recovery without holding up foreground searches for the full background startup timeout.
- Reuse a bounded search cache and cancel superseded requests to improve repeated searches on large indexes.
- Resume semantic indexing when legacy document text contains malformed UTF-8, without rewriting the original stored text.
- Resolve packaged application resources from the bundle, including packaged debug builds.

## Beta distribution

This beta continues the approved native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts must carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions. Updater signing does not provide operating-system publisher certification.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.

Cold searches on large indexes can still take seconds, and the cache uses additional memory. Q4 reduces the model download size; speed and retrieval quality depend on the workload. This update does not restore the search screen after a full Quit, and a large background reindex may take time to finish.
