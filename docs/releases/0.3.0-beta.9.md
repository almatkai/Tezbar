# Tezbar 0.3.0-beta.9

This beta replaces the WebView interface with a native Rust application. Every screen is drawn with GPUI; the launcher, search, settings, built-in commands and extension metadata run in Rust. JavaScript runs only inside the isolated Extension Worker, and only after you run or install a JavaScript extension.

## Native app

- The launcher, Settings, Clipboard History, Snippets, Notes, Vault, Emoji, Extensions, Indexing, System Monitor, Terminal, AI chat, Release Notes and onboarding are native screens.
- Starting Tezbar and using built-in commands never starts Bun. The first JavaScript extension you run starts one worker, later commands reuse it, and a stopped worker restarts only when you run an extension again.
- Pinned Bun 1.2.5 is still provisioned automatically for JavaScript extensions, with the published SHA-256 checksum verified before use.
- Voice input is removed: there is no Voice settings tab, push-to-talk dictation, speech-to-text model downloads or microphone permission. Read Aloud still speaks text with the system voice.

## Windows

- Ctrl is the primary modifier everywhere (shortcuts, footers and onboarding keycaps), and Ctrl+Space opens Tezbar.
- The launcher has one rounded frame, keeps its size when shown again, and can be dragged from any empty part of its header or footer.
- System Monitor, app discovery, app and file icons, system commands, keep-awake, read-aloud, "Open with", notifications and clipboard file access use Windows APIs directly instead of starting PowerShell or other helper processes.
- Vault unlocks with Windows Hello (PIN, fingerprint or face). The Vault key is encrypted for your Windows account, and copied secrets stay out of clipboard history and cloud clipboard and are cleared after 30 seconds.
- The terminal runs on ConPTY: shells exit cleanly, resizing follows the window, and several sessions can run side by side.
- Directory search uses your real home folder and hides hidden and system files.
- Store apps show their own icons, and app subtitles read like "Start Menu › Folder" instead of raw shortcut paths.
- Permissions lists only what applies to Windows and links to the matching Windows settings pages.

## Search and screens

- "settings", "notes", "vault" and "store" open Tezbar's own screens before same-named Windows apps or files.
- Built-in commands stay in the results even when many files match the same words, and Vault and Snippets appear once each.
- Esc leaves What's new and Permissions.
- Indexing and System Monitor show readable sizes instead of raw byte counts.
- Settings › Extensions shows commands as a readable list, and clipboard and conversion icons render correctly.
