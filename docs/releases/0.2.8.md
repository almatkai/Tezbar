## Choose your release channel

- Choose **Stable**, **Beta**, or **Alpha** in **Settings > App updates > Release channel**.
- Normal Tezbar installations start on **Stable**. Your choice is saved across restarts and upgrades.
- Switching channels immediately checks the selected channel for newer eligible updates.
- All channels share the same installation, settings, history, indexes, and shortcuts.
- Returning to Stable never installs an older version over newer shared data.

This release provides Windows x64 and macOS Apple Silicon installers for manual installation. The Windows installer is not Authenticode-signed; the macOS application is ad hoc signed and is not notarized. These downloads do not enable a signed automatic update feed.
