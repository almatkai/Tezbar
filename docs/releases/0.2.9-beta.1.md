## Optional local semantic search

- Download and enable **EmbeddingGemma 2** in **Settings > Knowledge > Semantic search**.
- Search documents and code by meaning across languages. The model runs locally after download.
- Built-in search remains the default. Model files download only when you request them.
- Smart and Deep folders use the semantic index; Basic folders keep keyword search.
- Index existing extracted text without repeating OCR. Pause, retry, or remove the optional model from Settings.
- Keep using your current installation, settings, history, and indexes when choosing Stable, Beta, or Alpha.

This Beta is newer than Stable 0.2.8. It provides Windows x64 and macOS Apple Silicon installers for manual installation. The Windows installer is not Authenticode-signed; the macOS app is ad hoc signed and is not notarized. These downloads do not enable a signed automatic update feed.

The initial model integration supports text and code, including extracted PDF and OCR text. Raw images, audio, and video are not embedded. The optional model download is approximately 310 MB, plus a platform-specific runtime.
