## Keep large Gemma indexes moving

- Build Gemma embeddings from the text already extracted by built-in indexing, without repeating OCR or resetting the text index.
- Avoid sorting the entire corpus for each small embedding batch. Resume each pass from its last chunk.
- Keep large-corpus counts responsive with a covering database index and a cache that starts after the count finishes.
- Update semantic progress when each batch is saved. Settings waits for the previous status request instead of queuing overlapping requests.
- Add an explicit Refresh status button and a Start semantic indexing action when work is pending.

This Beta provides Windows x64 and macOS Apple Silicon installers for manual installation. Windows is not Authenticode-signed; macOS is ad hoc signed and is not notarized. EmbeddingGemma 2 remains optional, and existing model files and extracted content are preserved.
