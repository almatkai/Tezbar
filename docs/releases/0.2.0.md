## More reliable Windows updates

- Tezbar verifies downloaded updates before installing them.
- Update checks now offer a new version only when an installer is available for your platform.
- If a release has no installer for your platform, Tezbar keeps your current version instead of showing an update error.

## Release notes inside Tezbar

- See what changed when you first open Tezbar after an update.
- Read these notes offline, right inside the app.
- Reopen them anytime from **Settings → App Updates → What's New**.
