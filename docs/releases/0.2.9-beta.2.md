## Discover releases in your selected channel

- Find newer published Stable, Beta, or Alpha installers even when automatic updates are not available for that release.
- See the available version, its release notes, and a Download Installer button that opens the correct installer for your platform.
- Manual releases also appear in your search bar. They never download or install automatically.
- A failed GitHub release check reports an error instead of incorrectly claiming there is no newer release.
- Keep the optional local EmbeddingGemma 2 search from Beta 0.2.9-beta.1. Enable it in Settings > Knowledge > Semantic search.

This Beta provides Windows x64 and macOS Apple Silicon installers for manual installation. Windows is not Authenticode-signed; macOS is ad hoc signed and is not notarized. Signed automatic updater feeds remain separate from manual installer discovery.
