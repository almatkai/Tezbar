## Configurable chunking and indexing speed for semantic search

- Add indexing speed control to Knowledge settings: choose between Slow & Light, Medium (balanced default), and Fast & Heavy.
- Dynamically scale EmbeddingGemma runtime thread pool between 2, 4, and 8 threads based on selected speed profile.
- Pace background queue processing and backfill loops with adaptive delays to keep the system responsive or maximize throughput.
- Persist indexing speed preferences across app restarts in the knowledge database.
- Provide quick inline speed switching directly inside Knowledge Embedding Settings.

This Beta provides Windows x64 and macOS Apple Silicon installers for manual installation. Windows is not Authenticode-signed; macOS is ad hoc signed and is not notarized. EmbeddingGemma 2 remains optional, and existing model files and extracted content are preserved.
