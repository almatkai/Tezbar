# Tezbar 0.3.0-beta.8

This beta combines the changes already integrated into the earlier beta branches with automatic Bun setup for JavaScript extensions and terminal width fitting.

## Extensions

- Find an existing Bun runtime in the app cache, `~/.bun/bin`, common install locations, or `PATH` before downloading anything.
- When no usable runtime exists, install pinned Bun 1.2.5 into the app data directory. The archive is verified against Bun's published SHA-256 checksums before extraction, and the installed runtime is confirmed by running `bun --version`.
- Provisioning runs only when the JavaScript Extension Worker starts. Tezbar core features and Native V2 extensions continue to run natively in Rust without Bun.
- Report `runtime-downloading`, `runtime-installing`, and `runtime-ready` phases on the extension worker status channel.
- When the download fails or checksum verification does not match, the error points to https://bun.sh for a manual install.

## Terminal

- Use the available terminal width once character measurements are ready, instead of remaining at the initial 80 columns.
- Keep the grid and shell dimensions synchronized when the window grows or shrinks and font measurements change.
- Avoid repeated fitting during ordinary output and clean up fitting listeners when the terminal closes.

## Validation

- All earlier beta integration and release branches are accounted for in this branch, including the terminal fix merged into beta.7 and the beta.17 performance verification notes.
- TypeScript checks and the full unit and integration suite pass, including five terminal fitting regression tests.
- A browser check verifies terminal fitting after wider and narrower container sizes and changed font measurements.
- Rust library checks and Bun runtime unit tests pass.
- An opt-in integration test downloads, verifies, extracts, and runs the pinned runtime end to end.
