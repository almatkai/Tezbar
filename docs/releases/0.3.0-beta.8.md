# Tezbar 0.3.0-beta.8

This beta makes JavaScript extension installation self-contained: Tezbar now finds or installs the Bun runtime it needs instead of failing with "Bun runtime is not installed".

## Extensions

- Find an existing Bun runtime in the app cache, `~/.bun/bin`, common install locations, or `PATH` before downloading anything.
- When no usable runtime exists, install pinned Bun 1.2.5 into the app data directory. The archive is verified against Bun's published SHA-256 checksums before extraction, and the installed runtime is confirmed by running `bun --version`.
- Provisioning runs only when the JavaScript Extension Worker starts. Tezbar core features and Native V2 extensions continue to run natively in Rust without Bun.
- Report `runtime-downloading`, `runtime-installing`, and `runtime-ready` phases on the extension worker status channel.
- When the download fails or checksum verification does not match, the error points to https://bun.sh for a manual install.

## Validation

- Rust library checks and Bun runtime unit tests pass.
- An opt-in integration test downloads, verifies, extracts, and runs the pinned runtime end to end.
