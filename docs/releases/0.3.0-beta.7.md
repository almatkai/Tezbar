# Tezbar 0.3.0-beta.7

This beta fixes the Color Wheel layout regression in beta.6 and improves AI agent conversation isolation, permissions, and reliability.

## AI agent mode

- Keep each conversation's response stream, context, approvals, and saved history separate. Switching conversations preserves background work without inserting its output into another chat.
- Keep pending approvals available when returning to an active conversation.
- Start a fresh conversation for every New Chat command, and capture a fresh screenshot for repeated screen commands.
- Prevent slow history/config loading from resetting a conversation the user has already started.
- Discard screenshot captures that finish after navigating to another conversation or hiding the surface.
- Require confirmation for unsupported shell syntax and check every command in an automatically allowed chain. Request Review now takes priority over remembered shell-command approvals.
- Connect Copilot agent runs to the correct Pi provider using the sign-in configured in Tezbar.
- Handle Cyrillic and emoji safely when generating conversation titles.
- Release completed background chat instances after saving their history, while keeping unsaved responses available if persistence fails.

## Color Picker

- The wheel stays circular and centered at narrow and wide launcher sizes, including in the macOS WebKit renderer.
- Color formats scroll inside their panel without stretching the wheel area or pushing the wheel below the footer.
- The formats panel adapts to the available width, and panel borders use their intended translucent color.

## Validation

- TypeScript checks and the full unit and integration test suite pass.
- Regression coverage exercises concurrent chats, navigation, approvals, screenshot races, persistence failures, shell policy, Copilot RPC configuration, and Unicode title generation.
- Browser regression coverage checks both native-form and detail-view wheels at three widths and two heights in Chromium and WebKit, including pointer selection and format copying.
