## Per-display window layout and launcher appearance

- Support resizable launcher with edge and corner drag handles across monitors.
- Save and restore launcher size, scale factor (75%–200%), and window position per monitor.
- Show background task status and indexing progress for semantic search and chunking.
- Add launcher appearance controls to **Settings → General** and hint bar.

This Beta provides signed Windows x64 and macOS Apple Silicon updates and installers.
