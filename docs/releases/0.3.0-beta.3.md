# Tezbar 0.3.0-beta.3

Release date: 2026-11-02

This beta fixes the Vault authentication lifecycle on macOS and keeps Knowledge settings steady during background status refreshes.

## Vault

- Fix window disappearing during biometric / password authentication: suppress blur-hide while Touch ID or system password prompt is displayed.
- Automatically refocus and restore the main window upon completion of device-owner authentication so the unlocked Vault contents are immediately visible.
- Add surface routing and window-shown focus synchronization for Vault view.

## Knowledge settings

- Fix the brief layout jump every 1.5 seconds while the Knowledge tab is idle: automatic status refreshes now preserve the loaded controls without inserting a temporary loading banner.
- Keep background refreshes quiet when the settings window becomes visible again, while preserving loading feedback for initial loads and manual refreshes.

## Beta distribution

This beta continues the 0.2.9-beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
