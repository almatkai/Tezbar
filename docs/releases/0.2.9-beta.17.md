# Tezbar 0.2.9-beta.17

Release date: 2026-10-30

This beta improves search responsiveness, reduces repeated background work, and includes an optimized Deep Search runtime for macOS Apple Silicon. It also fixes launcher contrast in the light theme.

## Search and responsiveness

- Dispatch the latest search input without the previous fixed waits, keeping typing responsive during ordinary search, Deep Search, and background indexing.
- Coalesce rapid input changes, bound concurrent search requests, and prevent older replies from replacing the latest results.
- Reuse native search scoring state and narrow source selection to reduce repeated query work.
- On macOS Apple Silicon, avoid repeated document-size lookups in full-text ranking. This optimization remains limited to the validated platform.
- Preserve input-method composition and recover search correctly after hiding and reopening the launcher.

## Deep Search memory and background work

- Bundle a pinned embedding runtime for macOS Apple Silicon that avoids unused output allocations in the supported embedding path, reducing model-process memory in the measured workloads.
- Verify the bundled runtime before use and activate it without changing existing model weights or rebuilding the user's index.
- Park unused embedding workers, reduce repeated idle background work, and release transient image data sooner.
- Keep active model-download progress updating while other background work sleeps.

Performance gains depend on the workload. These changes do not establish a fivefold improvement across the whole app or a fivefold reduction in total app RAM. Performance measurements were qualified on macOS Apple Silicon; they are not Windows benchmark claims.

## Launcher fixes

- Draw the launcher window border above the search header, results and footer, so it stays visible on light backgrounds. The border is also slightly darker in the light theme.
- Replace the thick accent band under the search field with the same 1px divider used in the dark theme.
- Make the update status row readable in the light theme: darker green, blue and teal text and pills, and white text when the row is selected. Remove the decorative glow from its icon and pill.
- Keep the pinned Trash target from overlapping launcher hotkeys.

## Beta distribution

This beta continues the beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
