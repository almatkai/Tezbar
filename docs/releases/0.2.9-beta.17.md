# Tezbar 0.2.9-beta.17

Release date: 2026-10-29

This beta fixes launcher contrast in the light theme.

- Draw the launcher window border above the search header, results and footer, so it stays visible on light backgrounds. The border is also slightly darker in the light theme.
- Replace the thick accent band under the search field with the same 1px divider used in the dark theme.
- Make the update status row readable in the light theme: darker green, blue and teal text and pills, and white text when the row is selected. Remove the decorative glow from its icon and pill.

## Beta distribution

This beta continues the beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
