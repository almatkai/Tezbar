# Tezbar 0.3.0-beta.5

Release date: 2026-11-02

This beta fixes how extension forms submit, redesigns single-prompt forms, and lets you choose an icon for each Vault item.

## Extension forms

- Press ⌘↵ (Ctrl+↵ on Windows) to submit a form from any field, including multi-line text areas. Plain ↵ in a text area now inserts a new line; ↵ in single-line fields still submits.
- The footer hint shows the shortcut that actually submits the form.
- Forms with a single text area, such as Ask Perplexity, open as a full-height prompt aligned with the title, with the cursor already in place.
- Other forms use a tighter label column and a neutral focus outline.
- Progress appears in the footer and clears when the action finishes, instead of staying on "Working" indefinitely. Repeated submits are ignored while one is running.

## Vault

- Choose an icon for any item from 43 built-in icons in the editor (⌘E). Filter by name, move with the arrow keys, or pick "Use default" to return to the type icon.
- Existing items keep their type icon; no migration is needed.

## Beta distribution

The macOS app keeps the pinned Apple Development certificate identity introduced in beta.4 (Team ID `UBRTH86SZ3`); it is not Developer ID notarized. The Windows installer continues the beta exception without Authenticode signing. Both updater artifacts carry Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
