## Search keyboard layout correction

- Search now recognizes English names typed with the Russian keyboard layout: `МЫ СЩВУ` finds Visual Studio Code, and `сркщьу` finds Chrome.
- Also supports Russian words typed with English keys and mixed-layout queries.
- Preserves the original query and gives literal matches priority. The same correction applies to instant cached search results.
- Keeps the launcher and app design from Beta 9.

## Pinned commands ordering

- Newly pinned commands now append to the bottom of the rail by default, preserving existing pin shortcuts and order.
- Drag-and-drop continues to support placing pins into any custom position.

This Beta includes Windows x64 and macOS Apple Silicon installers with signed updater artifacts. OS code-signing and Apple notarization are not provided in this testing preview.
