# Tezbar 0.3.0-beta.2

Release date: 2026-11-01

This beta fixes the update restart icon in the launcher and stabilizes Knowledge incremental indexing against churning loops.

## Launcher & Interface

- Fix the update restart icon in search results: replaced the distorted, overlapping SVG path with a clean, circular rotate-arrow glyph that aligns with the system icon stroke and sizing.

## Knowledge & Indexing

- Back off churning incremental sources: add per-path retry deadlines with exponential backoff from 60 seconds to 30 minutes, bounded history, and quiet-period resets.
- Reconcile watcher paths without rebuilding full indexing jobs and coalesce watcher events to prevent reindex churn loops.

## Beta distribution

This beta continues the 0.2.9-beta.15 native-signing exception: the macOS application is ad-hoc signed without Apple Developer ID or notarization, and the Windows installer has no Authenticode signature. Both updater artifacts carry verified Tauri updater signatures matching the key already trusted by installed Tezbar versions.

Supported platforms: macOS Apple Silicon arm64 and Windows x64. No Intel Mac installer is included.
