## Release notes on your terms

- **Show Updated Version** now appears first in the launcher list after an update.
- Select it and press **Enter** to read what's new on a page inside Tezbar.
- Press **Escape** or use the back arrow to return to the launcher.
- The automatic release-notes popup has been removed. The launcher item stays until you open the notes.
- You can find the notes again by searching **Show Updated Version** or through **Settings → App Updates → What's New**.

Release notes remain available offline. Fresh installations continue to start with onboarding.
