## Critical clipboard and interface fixes

- Preserve Unicode when copying and reading text on macOS, including Cyrillic, Kazakh, Arabic, Asian scripts, and emoji. Clipboard subprocesses now explicitly use UTF-8 even when the app is launched without a UTF-8 locale.
- Wait for clipboard writes to finish before reporting success, and report failed writes.
- Prevent accidental selection and dragging of system interface text while preserving selection in inputs, text previews, and Markdown answers.
- Make Markdown code blocks, copy controls, and syntax highlighting follow the light theme.

Previously damaged clipboard-history entries cannot be reconstructed automatically. Copy the original text again after updating.

This release retains the existing application identity and user profile. It does not include the in-progress launcher redesign or the additional experimental Beta launcher-layout changes.
