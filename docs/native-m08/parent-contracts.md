# Parent-owned M8 core and shared-model contracts

These additions are implementation infrastructure, not M8/full-migration acceptance. The active M8 implementation owns its native view/tests separately. All source changes remain local on `feat/native-gpui-app`.

- `agent:run` accepts optional top-level `runSelection: {provider, model}`. Both identifiers must be nonempty, bounded, trimmed text; other keys, partial objects and null are rejected before run registration. The run resolves the canonical provider/auth configuration and then applies the explicit routing snapshot. Disabled/removed custom providers fail rather than silently switching. Omitted snapshots preserve existing callers. No credentials or arbitrary config are accepted in this field.
- Approval mode retains existing live behavior. Native chat omits top-level `approvalMode`; its explicit user edits go through the shared SettingsStore, and later tools read the current canonical mode. Changing the mode never resolves an outstanding approval.
- `ChatController::capture_failed(token)` unlocks only the matching capture. `attach_references(session, Vec<Reference>) -> Result<usize, &str>` admits only image references into the visible active nondeleted/nonbusy draft, deduplicates and atomically enforces eight images. The adapter still owns request/revision/mount and decode/storage fences.
- `begin_clear() -> Vec<Effect>` fences all retained conversations, including hidden/dirty/preparing owners. Execute Cancel effects; collect DeleteConversation tickets for ONE canonical `chat:clear`; settle every ticket with `delete_result` on success or failure and execute all returned persistence effects. Do not approximate all saved conversations with the bounded history list. The view must also fence overlapping clear/navigation/preparation work.
- Native history is resolved in this order for the exact selected session/turn IDs: canonical runtime store, minimal durable legacy `chat_turns`, then supplied dirty unsaved fallbacks. The legacy query excludes stages/timeline/image bodies, refuses oversized text, and never uses rows from another session or a tombstoned session. Missing image descriptors become an explicit unavailable-image marker; canonical signed/tool/image data remain authoritative.
- Shared Markdown discovers image sources during content updates, not rendering. Typed `ImageTicket` rejects results for removed/re-added sources. `image_requests`, `set_image(ticket, Option<Arc<RenderImage>>, cx)` and explicit `reset_images` let the adapter's bounded ImageCache own decoding/atlas release. The view keeps Weak references and displays native images or neutral loading/unavailable rows.

Parent canonical preview/clear addition: finite `chat:image` accepts `{sessionId,turnId,index}` (0–7), checks the durable nondeleted USER-turn identity, reads only that canonical image blob and returns `{mimeType,data}` or null. It never substitutes an assistant transcript's earlier image; a missing earlier blob does not shift later attachment indices. `chat:clear` accepts the optional second argument of owned preparing session IDs (bounded64), merges active runs and commits tombstones before late appends. Invalid IDs fail before clearing. Two regressions pass in `/tmp/tezbar-m8-parent-history-image.log`. New native transport/export wiring is a separate uncommitted integration input until M8 actually compiles.
